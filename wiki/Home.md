# Urna eletrônica em Java

Pessoal, comecem pelo tipo de projeto que o grupo já usa. Em cada aula vocês vão encontrar o conceito, uma experiência pequena, o código e o que observar no resultado. Para a entrega, as duas turmas usam Swing. JavaFX fica como prática complementar.

## Por onde começar

Se o grupo já tem um projeto Java simples no IntelliJ ou no NetBeans, abram [Primeiro projeto Java comum](https://github.com/NirtonAfonso/Tutorial-Firebase/wiki/Projeto-Java-comum). Quem já tem um `pom.xml` ou quer migrar pode começar por [Primeiro projeto Maven e migração](https://github.com/NirtonAfonso/Tutorial-Firebase/wiki/Projeto-Maven). Depois as duas trilhas se encontram na aula de Swing. Para baixar os códigos, usem **Code → Download ZIP** na [página do repositório](https://github.com/NirtonAfonso/Tutorial-Firebase), extraiam o ZIP e abram só a pasta do exercício. Cada pasta Maven tem seu próprio POM. No Java comum, os fontes ficam em `src`.
